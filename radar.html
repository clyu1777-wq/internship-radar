③ 工具箱:持续盯岗的渠道

直接回答你的第一个问题:没有任何一个现成工具能同时覆盖「游戏策划 + FDE、中国 + 美国」。美国侧聚合器普遍不设 game design 类目,中国侧没有开放 API。下面这套组合拳是实测后的最优配置。

美国侧 · 发现

SimplifyJobs/Summer2027-Internships

GitHub 46.1k★,每日更新的美国实习榜单(SWE/数据/量化/PM/硬件五类)。姊妹榜 vanshb03 版(原 cvrve 系列)口径略不同,两个一起 Watch。

FIT FDE 岗好用(搜 forward deployed / solutions);明确不收 game design 岗,游戏公司只出现 SWE/PM。当「开闸警报器」用。

HiringCafe

直接爬 12 万+ 公司官方招聘页的免费聚合器,筛选维度极细,支持保存搜索。

FIT 唯一能同时服务两条线的:Internship + "game design" 和 "forward deployed" 各存一个搜索。岗位真实性高、比 LinkedIn 快;中国岗基本没有。

Hitmarker

游戏/电竞行业垂直招聘板,免费,含 newsletter 订阅。

FIT 少数按「游戏行业」组织的板子,game design intern 密度远高于通用平台,补足中小工作室盲区。欧美为主。

LinkedIn Job Alerts

搜索页开 Job Alert 开关即可,最多 20 个并存,每日邮件+App 推送。

FIT 被动发现性价比之王。建议 4 个 alert:game design intern / forward deployed engineer / solutions engineer intern / technical program intern。中国大陆岗覆盖差。

Jobright.ai + intern-list.com

前者喂简历做 AI 匹配,后者每小时更新 + 免费邮件提醒。

FIT Jobright 的匹配引擎对「职位名不统一」的 FDE 类岗(常叫 Solutions Engineer / Deployment Strategist)有优势。均仅美国。

Simplify 插件 + Extern 时间线指南

Simplify:ATS 自动填表 + 投递追踪看板,免费。Extern:逐家大厂的开放时间预测(本页多数 opens-soon 日期的依据)。

FIT 美国实习动辄几十上百投,autofill 省大量时间;9 月前把 Extern 各家指南复查一遍。

中国侧 · 发现

牛客网

实习广场有游戏策划类目 + 微信扫码职位订阅(周更);讨论区常比官方渠道更早流出大厂策划实习信息,还有面经。

FIT 中国游戏策划实习第一优先工具,盯腾讯/库洛等秋招官宣比刷各家 JS 官网省事。

实习僧

实测搜「游戏策划」6 页+ 结果,可按城市/月份/每周天数/转正/日薪筛选。

FIT 策划日常实习密度最高的单一站点;无订阅功能,需手动按「最新」刷。寒假找短期到岗实习按城市+时长筛。

超级简历 校招汇总 + BOSS直聘

超级简历按批次/截止时间结构化筛选,直链网申入口;BOSS 直聘中小厂实习岗多但强反爬,只能人肉刷 App。

FIT 超级简历适合每周扫一遍「哪些游戏公司开了网申」;BOSS 是中小厂策划实习的实际主战场。

自动化 · 可以让 Claude 帮你搭

Greenhouse / Lever / Ashby 公开 API 轮询

三大 ATS 都有无鉴权 JSON 接口(如 boards-api.greenhouse.io/v1/boards/epicgames/jobs);Epic、Rockstar(rsgur)、Bungie、SIE、Scale、Palantir(Lever)、OpenAI/Netic(Ashby)全在上面。

FIT 写个定时脚本每天 diff 一次 "intern" + "game design" + "forward deployed" 关键词,第一时间抓到上新——本页所有 open 岗位就是这么验证的。

JobSpy(python-jobspy)

开源 Python 库,一次调用同时抓 LinkedIn/Indeed/Glassdoor/Google 等 7 个板子,导出 CSV。

FIT 可以接进你暑期实习已有的 scraper 工作流做每日 diff。反爬需代理+间隔;对中国站点无效,国内侧仍靠牛客/实习僧手动。

数据时效。本页为 2026-08-07 快照。「待核实」= 官网 JS 渲染无法程序化读取,信息依据官方简章/通稿转载;「预计」时间按上届周期推算。投递前以官网实时信息为准。
